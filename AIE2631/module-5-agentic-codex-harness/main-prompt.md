
أنشئ مشروع Full-Stack متكامل باستخدام TypeScript باسم **ShihrBorad** داخل المجلد الحالي الفارغ.

ShihrBorad منصة داخلية لإدارة ومتابعة العمليات المالية والتشغيلية في مؤسسة مالية، تتيح للموظفين والإدارة متابعة المعاملات المالية وطلبات الموافقة ومؤشرات الأداء. اجعل المشروع أساسًا عمليًا قابلًا للتطوير والمراجعة لاحقًا من حيث Architecture, Security, Performance, Accessibility وCode Quality.

### 1. البنية التقنية - Tech Stack

- Frontend: React, Vite, TypeScript.
- Backend: Express, TypeScript.
- بيانات محلية تجريبية (Local Seeded Data) دون خدمات خارجية.
- npm Workspaces بهيكل واضح: frontend / backend / shared.
- Vitest للاختبارات.
- ESLint وTypeScript للتحقق من جودة الكود.

### 2. الوظائف الأساسية - Product Features

- تسجيل دخول تجريبي (Mock Authentication) بصلاحيات الموظف والمشرف والمدير.
- لوحة تحكم مالية تعرض مؤشرات الأداء والإحصائيات والرسوم البيانية وأحدث الأنشطة.
- جدول للمعاملات المالية يدعم البحث والتصفية والترتيب.
- صفحة تفاصيل المعاملة المالية وسجل حالاتها.
- إنشاء وتعديل المعاملات المالية وطلبات الموافقة.
- إدارة طلبات الاعتماد ومتابعة حالاتها.
- سجل الأنشطة والعمليات (Audit Log).
- إدارة الحساب وإعدادات المؤسسة.
- Express API Routes للمعاملات والموافقات والأنشطة والإعدادات والجلسات التجريبية.
- بيانات تجريبية متنوعة للمستخدمين والمعاملات والفروع والحالات، باستخدام الريال اليمني.

### 3. تجربة المستخدم والتصميم (UI/UX)

- واجهة عربية بالكامل، حديثة واحترافية، تدعم RTL بصورة صحيحة.
- استخدام خط عربي حديث مثل Cairo أو Thmanyah إذا كان متاحا محليا.
- هوية بصرية مالية مؤسسية بألوان متناسقة وأيقونات واضحة.
- قائمة تنقل جانبية، وبطاقات مؤشرات مالية، ورسوم بيانية تفاعلية.
- دعم الوضع الفاتح والداكن (Light/Dark Mode).
- تصميم متجاوب (Responsive Design) مع مراعاة إمكانية الوصول وحالات التحميل والأخطاء والبيانات الفارغة.

### 4. متطلبات المشروع - Project Requirements

- حافظ على بساطة المشروع، مع ضمان عمل جميع وظائفه الأساسية.
- طبق الصلاحيات والتحقق من المدخلات وقواعد العمليات المالية على مستوى Backend، وليس الواجهة فقط.
- لا تُضف عمدًا ثغرات أمنية أو عناصر غير قابلة للوصول أو وظائف معطلة.
- لا تستخدم بيانات مالية حقيقية أو API Keys أو قواعد بيانات بعيدة أو خدمات مستضافة أو اعتماديات مدفوعة.
- أنشئ README.md يتضمن تعليمات الإعداد والتشغيل والبناء والاختبار والتحقق.
- أنشئ AGENTS.md يوضح بنية المشروع وأوامره وقيوده وقواعد التطوير ومتطلبات التحقق.
- تأكد من عمل الأوامر التالية من المجلد الرئيسي:

  - npm install
  - npm run dev
  - npm run build
  - npm run test
  - npm run lint
  - npm run typecheck

- هيئ Git وأنشئ .gitignore مناسبًا، ونفذ Baseline Commit إذا كانت هوية Git معدة.
- شغّل جميع اختبارات وأوامر التحقق، وعالج الأخطاء قبل إنهاء المهمة.
