# Skill Distillation

استخدم `$skill-creator` لتحليل مهارات Frontend Design الثلاث التي استخدمناها في هذا المشروع. حدّد نقاط القوة والقدرات الفريدة لكل مهارة، واستخلص أفضل الممارسات والتعليمات وأنماط التصميم، وأزل التكرار والتعارضات والتعليمات غير الضرورية. راجع أيضًا القرارات التصميمية الناجحة التي طبقناها في المشروع، ثم ادمج المعرفة المستخلصة في مهارة مخصصة ومستقلة باسم `frontend-mastery`، تتوافق مع هوية المشروع وتقنياته ومتطلباته، مع التركيز على UI/UX، وDesign System، وResponsive Design، وRTL، وAccessibility، وجودة الكود. راجع تراخيص المصادر وأمانها، وحافظ على حقوقها، وطبّق Progressive Disclosure لتقليل استهلاك السياق. أنشئ المهارة في `.agents/skills/frontend-mastery/SKILL.md` وفق معيار Agent Skills، وأضف الملفات المرجعية عند الحاجة فقط. تحقّق من صحة بنية المهارة وقابليتها لإعادة الاستخدام، دون تعديل الكود الحالي للمشروع أو المهارات الأصلية.

----

استخدم `$frontend-mastery` لتصميم وتطوير لوحة تحكم مالية حديثة باللغة العربية، تدعم RTL وResponsive Design، مع الالتزام بالهوية البصرية للمشروع ومعايير UI/UX وإمكانية الوصول، دون استخدام المهارات التصميمية الثلاث الأصلية.

# Supabase

[1] استخدم Supabase MCP للتحقق من الاتصال بالمشروع، واعرض اسم المشروع والجداول الحالية وبنية قاعدة البيانات وحالة الاتصال والأدوات المتاحة، دون إجراء أي تعديلات على قاعدة البيانات.


[2] حلّل مشروع ShihrBoard الحالي، بما يشمل الواجهات والمكونات والبيانات التجريبية والمؤشرات المالية. استخدم Supabase MCP لتصميم قاعدة بيانات PostgreSQL متكاملة تتوافق مع احتياجات المشروع، وحدّد الجداول والعلاقات وأنواع البيانات والمفاتيح الأساسية والخارجية والفهارس. اعرض خطة Database Schema أولًا، وبعد موافقتي نفّذها باستخدام SQL Migrations، وأنشئ Dataset اصطناعية واقعية للاختبار، مع تفعيل RLS وتطبيق سياسات الوصول المناسبة، دون تغيير التصميم الحالي للمشروع أو حذف أي بيانات موجودة.

[3] اربط مشروع ShihrBoard بقاعدة بيانات Supabase باستخدام SDK الرسمي المتوافق مع التقنيات الحالية للمشروع. استبدل البيانات الوهمية Mock Data بالبيانات الفعلية، واضبط Environment Variables، وأنشئ طبقة Data Access منظمة وقابلة لإعادة الاستخدام. اربط المؤشرات المالية والجداول والرسوم البيانية بالبيانات الفعلية، مع معالجة حالات Loading وError وEmpty State، والحفاظ الكامل على التصميم والهوية البصرية الحالية.

[4] نفّذ End-to-End Validation لتكامل مشروع ShihrBoard مع Supabase. تحقّق من الاتصال والجداول والعلاقات وصحة البيانات وعمليات CRUD ودقة المؤشرات المالية وسياسات RLS وصلاحيات المستخدمين، وافحص Security Advisors وPerformance Advisors والسجلات Logs. اختبر التطبيق فعليًا، وعالج الأخطاء دون تعطيل ضوابط الأمان، ثم قدّم تقريرًا مختصرًا بالاختبارات ونتائجها والمشكلات المتبقية.
